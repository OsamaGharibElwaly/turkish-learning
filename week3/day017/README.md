## 🌍 Countries & Nationalities

Pay attention to the difference between **country** and **nationality**:

| Country 🇬🇧 | Turkish country | Nationality  |
| ------------ | --------------- | ------------ |
| China        | **Çin**         | **Çinli**    |
| Russia       | **Rusya**       | **Rusyalı**  |
| Iran         | **İran**        | **İranlı**   |
| France       | **Fransa**      | **Fransalı** |
| Italy        | **İtalya**      | **İtalyalı** |
| Egypt        | **Mısır**       | **Mısırlı**  |

### Useful pattern

**Ben + nationality + -(y)ım**

> **Ben Çinliyim.**
> I am Chinese.

> **Ben İranlıyım.**
> I am Iranian.

> **Ben Mısırlıyım.**
> I am Egyptian.

Notice:

**Çinli + yim → Çinliyim**
**İranlı + yım → İranlıyım**
**Mısırlı + yım → Mısırlıyım**

# 🧠 Important grammar: -ı / -i / -u / -ü

This page is very useful for learning the **accusative case**.

Look at:

> **Pilavı**
> **Salyangoz**
> **Lazanyayı**
> **Falafeli**

When the food is the **specific object** of the verb, Turkish can add:

**-(y)ı / -(y)i / -(y)u / -(y)ü**

### Examples from the text

**Pilavı yapıyoruz.**
→ We make the pilaf.

**Lazanyayı tavsiye ediyorum.**
→ I recommend the lasagna.

**Falafeli seviyorum.**
→ I like falafel.

For a word ending in a vowel, we add **y**:

**lazanya + yı → lazanyayı**

# ❤️ Very useful expression: bayılmak

> **Pelmeniye bayılıyorum.**

Literally, **bayılmak** = "to faint."

But in this context:

> **Pelmeniye bayılıyorum.**
> = **I absolutely love pelmeni. / I'm crazy about pelmeni.**

This is stronger than simply:

> **Pelmeniyi seviyorum.**
> = I like/love pelmeni.

### Pattern

**Bir şeye bayılmak**
= to absolutely love something

**Kahveye bayılıyorum.**
= I absolutely love coffee.

**Türk yemeklerine bayılıyorum.**
= I absolutely love Turkish food.

---

# 🥘 "ile" = with

The text says:

> **Safran ve pirinç ile yapıyoruz.**

= **We make it with saffron and rice.**

**ile** = with

You can also attach **-le/-la** to the noun:

**pirinç ile** → **pirinçle**
**arkadaş ile** → **arkadaşla**

Both mean **with**.

# ⭐ Sentences worth memorizing

These are the most useful patterns from this page:

**Benim adım ...**
→ My name is ...

**Ben ...liyim / ...lıyım.**
→ I am ...

**... çok lezzetli.**
→ ... is very delicious.

**... farklı bir yemek.**
→ ... is a different dish.

**...-e/-a bayılıyorum.**
→ I absolutely love ...

**...-i/-ı seviyorum.**
→ I like/love ...

**... ile yapıyoruz.**
→ We make it with ...

**...-i/-ı tavsiye ediyorum.**
→ I recommend ...
