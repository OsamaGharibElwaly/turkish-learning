## 🔥 A2 Rule of Thumb

Remember these four patterns:

**Ne + verb + -(y)Ayım?**
→ **What should I...?**

> **Ne yapayım?** → What should I do?

**Verb + -(y)Ayım mı?**
→ **Shall I...?**

> **Seni arayayım mı?** → Shall I call you?

**Verb + -(y)Alım.**
→ **Let's...**

> **Gidelim.** → Let's go.

**Verb + -(y)Alım mı?**
→ **Shall we...?**

> **Gidelim mi?** → Shall we go?

### 📝 Small Note

A very common way to turn an adjective into an abstract noun in Turkish is:

**Adjective + -lik / -lık / -luk / -lük**

The suffix changes according to **vowel harmony**:

* **güzel → güzellik**
* **iyi → iyilik**
* **kötü → kötülük**
* **zengin → zenginlik**
* **genç → gençlik**

Think of it roughly as **“-ness / -ity / -hood”** in English:

> **güzel** → beautiful → **güzellik** → beauty
> **mutlu** → happy → **mutluluk** → happiness
> **genç** → young → **gençlik** → youth

**Important:** Not every adjective simply takes **-lik**; Turkish vowel harmony determines the form, and some words have established forms that are best learned individually.
