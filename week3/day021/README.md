# 6. Geçmiş zaman — Past tense

Example:
**Hastayım → Dün hastaydım.**

1. **Çalışkanım → Dün çalışkandım.**

2. **Mutluyum → Dün mutluydum.**

3. **Cömertsin → Dün cömerttin.**

4. **Tembeller → Dün tembellerdi.**

5. **Yorgunsunuz → Dün yorgundunuz.**

### The key pattern

| Present | Past                              |
| ------- | --------------------------------- |
| -im     | -dim / -dım / -dum / -düm         |
| -sin    | -din / -dın / -dun / -dün         |
| -       | -di / -dı / -du / -dü             |
| -iz     | -dik / -dık / -duk / -dük         |
| -siniz  | -diniz / -dınız / -dunuz / -dünüz |
| -ler    | -diler / -dılar / -dular / -düler |

For example:

**Mutluyum → mutluydum**
**Hastayım → hastaydım**
**Yorgunsun → yorgundun**
**Çalışkanız → çalışkandık**

The most important thing in this lesson is mastering **-DI past tense** and the difference between **-di** and **-miş**.
