Sure. This cheat sheet is about **Turkish verbals (fiilimsiler)**. Here are simple A1–B1-style examples for each suffix.

## 1. İsim-fiil — **-ma / -me, -ış / -iş / -uş / -üş, -mak / -mek**

Turns a verb into a **noun**.

| Suffix              | Example                           | English                           |
| ------------------- | --------------------------------- | --------------------------------- |
| **-ma/-me**         | **Yüzme** çok eğlenceli.          | Swimming is fun.                  |
|                     | Kitap **okuma** alışkanlığım var. | I have a reading habit.           |
| **-ış/-iş/-uş/-üş** | Onun **gülüşü** çok güzel.        | His/her smile/laugh is beautiful. |
|                     | **Gelişi** bizi mutlu etti.       | His/her arrival made us happy.    |
| **-mak/-mek**       | Türkçe **öğrenmek** istiyorum.    | I want to learn Turkish.          |
|                     | Erken **kalkmak** zor.            | Getting up early is difficult.    |

**Think:**
`öğren- → öğrenmek` = learning
`yüz- → yüzme` = swimming
`gül- → gülüş` = smile/laugh

# 2. Sıfat-fiil — participles

These usually turn a verb into something that **describes a noun**.

### **-an / -en** = who/that is doing

| Turkish                       | English                                                    |
| ----------------------------- | ---------------------------------------------------------- |
| **Gülen** kız benim kardeşim. | The girl **who is laughing** is my sister.                 |
| **Çalışan** adam doktor.      | The man **who is working** is a doctor.                    |
| **Gelen** öğrenciler sınıfta. | The students **who came/are coming** are in the classroom. |

**gel-en öğrenci** → the student who comes/came

---

### **-ası / -esi** = worth doing / desirable

| Turkish                | English                          |
| ---------------------- | -------------------------------- |
| **Görülesi** bir yer.  | A place worth seeing.            |
| **Yiyesin** bir yemek! | A dish you'd really want to eat! |

This one is less common in everyday beginner Turkish.

---

### **-mez / -maz** = that doesn't / won't

| Turkish                | English                      |
| ---------------------- | ---------------------------- |
| **Bitmez** bir aşk.    | An endless love.             |
| **Geçmez** bir ağrı.   | A pain that doesn't go away. |
| **Unutulmaz** bir gün. | An unforgettable day.        |

---

### **-ar / -er** = that does / tends to do

| Turkish        | English                    |
| -------------- | -------------------------- |
| **Akar** su.   | Running water.             |
| **Çıkar** yol. | A way out / an exit route. |
| **Yanar** dağ. | A burning/active volcano.  |

---

### **-dik / -dık / -duk / -dük** + possessive

Very important! Usually means **that... / which... / who...**

| Turkish                       | English                                |
| ----------------------------- | -------------------------------------- |
| **Okuduğum** kitap çok güzel. | The book **that I read** is very good. |
| **Sevdiğin** yemek hangisi?   | Which is the food **that you like**?   |
| **Gördüğümüz** adam öğretmen. | The man **whom we saw** is a teacher.  |

Pattern:

**oku + duk + um → okuduğum**
**sev + dik + in → sevdiğin**
**gör + dük + ümüz → gördüğümüz**

---

### **-ecek / -acak** = that will...

| Turkish                                 | English                                          |
| --------------------------------------- | ------------------------------------------------ |
| **Gelecek** hafta görüşürüz.            | We will meet next week.                          |
| **Yapacağım** iş çok önemli.            | The work **that I will do** is very important.   |
| **Gelecek** öğrenciler burada beklesin. | The students **who will come** should wait here. |

---

### **-miş / -mış / -muş / -müş** = supposedly / apparently / apparently having...

| Turkish                   | English                              |
| ------------------------- | ------------------------------------ |
| **Gelmiş** adam burada.   | The man who apparently came is here. |
| **Pişmiş** yemek hazır.   | The cooked food is ready.            |
| **Unutulmuş** bir hikâye. | A forgotten story.                   |

---

# 3. Zarf-fiil — adverbial verbals

These describe **how, when, why, or under what condition** an action happens.

### **-ip / -ıp / -up / -üp** = and then / by doing

| Turkish                          | English                                |
| -------------------------------- | -------------------------------------- |
| Eve **gidip** yemek yedim.       | I went home **and ate**.               |
| Duş **alıp** uyudum.             | I took a shower **and slept**.         |
| Kitabı **okuyup** sınava girdim. | I read the book **and took** the exam. |

---

### **-arak / -erek** = by doing / while doing

| Turkish                             | English                         |
| ----------------------------------- | ------------------------------- |
| **Gülerek** konuştu.                | He spoke **while laughing**.    |
| **Koşarak** eve gittim.             | I went home **by running**.     |
| **Çalışarak** başarılı olabilirsin. | You can succeed **by working**. |

---

### **-madan / -meden** = without doing

| Turkish                           | English                              |
| --------------------------------- | ------------------------------------ |
| Kahvaltı **yapmadan** çıktım.     | I left **without having breakfast**. |
| Bana **sormadan** karar verme.    | Don't decide **without asking me**.  |
| Uy**umadan** önce kitap okuyorum. | I read before sleeping.              |

---

### **-maksızın / -meksizin** = without doing

More formal than **-madan**.

| Turkish                                | English                                              |
| -------------------------------------- | ---------------------------------------------------- |
| Hiç düşün**meksizin** cevap verdi.     | He answered **without thinking**.                    |
| İzin **almaksızın** buraya giremezsin. | You can't enter here **without getting permission**. |

---

### **-dıkça / -dikçe / -dukça / -dükçe** = as/whenever/more...the more...

| Turkish                                   | English                                            |
| ----------------------------------------- | -------------------------------------------------- |
| Türkçe **öğrendikçe** daha çok seviyorum. | The more I learn Turkish, the more I like it.      |
| Çalış**tıkça** başarılı olursun.          | The more you work, the more successful you become. |
| Yaşlan**dıkça** daha sakin oluyor.        | As he gets older, he becomes calmer.               |

---

### **-ınca / -ince / -unca / -ünce** = when / after

| Turkish                       | English                                 |
| ----------------------------- | --------------------------------------- |
| Eve **gelince** beni ara.     | Call me **when you get home**.          |
| İşim **bitince** çıkacağım.   | I will leave **when my work finishes**. |
| Onu **görünce** çok şaşırdım. | I was surprised **when I saw him**.     |

---

### **-alı / -eli** = since doing

| Turkish                            | English                                                |
| ---------------------------------- | ------------------------------------------------------ |
| Türkiye'ye **geleli** iki ay oldu. | It's been two months **since I came to Turkey**.       |
| Türkçe **öğreneli** bir yıl oldu.  | It's been a year **since I started learning Turkish**. |
| Onu **görmeyeli** uzun zaman oldu. | It's been a long time **since I saw him**.             |

---

### **-ken** = while

| Turkish                                | English                                     |
| -------------------------------------- | ------------------------------------------- |
| Yemek **yerken** televizyon izliyorum. | I watch TV **while eating**.                |
| Çocuk**ken** İstanbul'da yaşadım.      | I lived in Istanbul **when I was a child**. |
| Ders çalışır**ken** müzik dinliyorum.  | I listen to music **while studying**.       |

---

### **-a / -e ... -a / -e** = repeatedly/by doing

Usually repeated verbs.

| Turkish                        | English                                |
| ------------------------------ | -------------------------------------- |
| **Koşa koşa** eve gitti.       | He went home **running**.              |
| **Güle güle** konuşuyorlar.    | They are talking **laughing**.         |
| **Düşüne düşüne** karar verdi. | He decided **after thinking it over**. |

---

### **-r ... -maz / -mez** = as soon as

Very common!

| Turkish                            | English                                     |
| ---------------------------------- | ------------------------------------------- |
| Eve **gelir gelmez** duş aldım.    | I took a shower **as soon as I came home**. |
| Onu **görür görmez** tanıdım.      | I recognized him **as soon as I saw him**.  |
| Uyanır **uyanmaz** kahve içiyorum. | I drink coffee **as soon as I wake up**.    |

**Formula:**
`verb + geniş zaman + verb + -maz/-mez`

---

### **-asıya / -esiye** = until / intensely

| Turkish                | English                                  |
| ---------------------- | ---------------------------------------- |
| **Ölesiye** çalıştı.   | He worked **to death / extremely hard**. |
| **Gülesiye** eğlendik. | We had an extremely fun time.            |

Less common in everyday beginner Turkish.

---

### **-casına / -cesine** = as if / in a ... manner

| Turkish                     | English                           |
| --------------------------- | --------------------------------- |
| **Çılgıncasına** dans etti. | He danced **crazily**.            |
| **Çocukçasına** sevindi.    | He became happy **like a child**. |
| **Delicesine** âşık oldu.   | He fell in love **madly**.        |

---
