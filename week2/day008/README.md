## PART 2: POSSESSIVE SUFFIXES (İYELİK EKLERİ)

### What are Possessive Suffixes?

Possessive suffixes show **ownership** - who something belongs to.

### The Possessive Suffix Table

| Person | Suffix | Example with "baba" (father) |
|--------|--------|------------------------------|
| Benim (My) | -(i)m | babam = my father |
| Senin (Your - sing.) | -(i)n | baban = your father |
| Onun (His/Her/Its) | -(s)i | babası = his/her father |
| Bizim (Our) | -(i)miz | babamız = our father |
| Sizin (Your - pl.) | -(i)niz | babanız = your father |
| Onların (Their) | -ları/-leri | babaları = their father |

### Vowel Harmony Rules for Possessive Suffixes

**For 1st person singular (Benim):**
- If word ends with consonant: add -ım, -im, -um, -üm
  - anne → **annem** (my mother)
  - baba → **babam** (my father)
  - okul → **okulum** (my school)

**For 2nd person singular (Senin):**
- If word ends with consonant: add -ın, -in, -un, -ün
  - anne → **annen** (your mother)
  - baba → **baban** (your father)
  - okul → **okulun** (your school)

**For 3rd person singular (Onun):**
- If word ends with consonant: add -ı, -i, -u, -ü
- If word ends with vowel: add -sı, -si, -su, -sü
  - anne → **annesi** (his/her mother)
  - baba → **babası** (his/her father)
  - okul → **okulu** (his/her school)

**For 1st person plural (Bizim):**
- If word ends with consonant: add -ımız, -imiz, -umuz, -ümüz
  - anne → **annemiz** (our mother)
  - baba → **babamız** (our father)
  - okul → **okulumuz** (our school)

**For 2nd person plural (Sizin):**
- If word ends with consonant: add -ınız, -iniz, -unuz, -ünüz
  - anne → **anneniz** (your mother)
  - baba → **babanız** (your father)
  - okul → **okulunuz** (your school)

**For 3rd person plural (Onların):**
- If word ends with consonant: add -ları, -leri
- If word ends with vowel: add -ları, -leri (with buffer)
  - anne → **anneleri** (their mother)
  - baba → **babaları** (their father)
  - okul → **okulları** (their school)

### Important Rules

**Rule 1: Vowel Dropping**
When a word has a **narrow vowel (ı, i, u, ü) in its second syllable** and we add a suffix starting with a vowel, that narrow vowel is **dropped**.

**Examples:**
- boyun + -um = **boynum** (my neck) [the 'u' is dropped]
- burun + -um = **burnum** (my nose) [the 'u' is dropped]
- şehir + -im = **şehrim** (my city) [the 'i' is dropped]

**Rule 2: Buffer 'n'**
When adding **case suffixes** (-A, -dA, -dAn, -I) after 3rd person possessive suffixes, we add a buffer **'n'** between them.

**Examples:**
- Onun evine gidiyorum. = I'm going to his/her house. (ev-i-ne = house-his-to)
- Onların sınıflarında bilgisayar var. = There's a computer in their classroom.
- Onun balkonunda oturuyoruz. = We're sitting on his/her balcony.

### Key Phrases

**Asking about origin:**
- **Soru:** Nerelisiniz? = Where are you from?
- **Cevap:** Türküm. / Türkiyeliyim. = I'm Turkish.

**Asking about mother tongue:**
- **Soru:** Anadiliniz ne? = What is your mother tongue?

- **Soru:** Hangi yabancı dilleri biliyorsunuz? = Which foreign languages do you know?
- **Cevap:** İngilizce ve Rusça biliyorum. = I know English and Russian.

- **Soru:** Arkadaşın nereli? = Where is your friend from?
- **Cevap:** Arkadaşım Çinli. = My friend is Chinese.
- **Soru:** Arkadaşın hangi dili konuşuyor? = What language does your friend speak?
- **Cevap:** O Çince konuşuyor. = He/She speaks Chinese.

### Language Suffix Rule

To make a **language name**, add the suffix **-cA** to the nationality root.

**Important:** If the word ends with one of the consonants **(ç, f, h, k, p, s, ş, t)**, the suffix changes to **-çA**.

- İngiliz + -ce = İngilizce (English)
- Arap + -ça = Arapça (Arabic)
- Rus + -ça = Rusça (Russian)

## THE ACCUSATIVE CASE - BELİRTME EKİ (y)I

### What is the Accusative Case?

The accusative case shows the **definite direct object** of a verb. It answers the questions **"Kimi?" (Who?) and "Neyi?" (What?)** .

### Accusative Suffix Table

| Last Vowel | Suffix | Example |
|------------|--------|---------|
| a, ı | -(y)ı | arabayı (the car) |
| e, i | -(y)i | evi (the house) |
| o, u | -(y)u | okulu (the school) |
| ö, ü | -(y)ü | sözlüğü (the dictionary) |

### When Must We Use the Accusative Case?

**1. When the object is specific/definite:**
- Babam araba yıkıyor. = My father is washing a car. (some car)
- Babam **arabayı** yıkıyor. = My father is washing **the car**. (that specific car)

**2. When the object is a proper noun:**
- **Ayşe'yi** bekliyor musun? = Are you waiting for **Ayşe**?
- **İstanbul'u** geziyorum. = I'm touring **Istanbul**.

**3. When the object is a pronoun:**
- Biz **onları** tanımıyoruz. = We don't know **them**.
- **Seni** bekliyorum. = I'm waiting for **you**.

**4. When the object has a possessive or genitive suffix:**
- **Kitabını** bana ver. = Give me **your book**.
- Her hafta **anneannemi** ziyaret ediyorum. = I visit **my grandmother** every week.

**5. When the object has a demonstrative adjective (bu, şu, o, hangi, bütün, bazı):**
- **Bu elbiseyi** alıyorum. = I'm buying **this dress**.
- **Hangi kalemi** istiyorsun? = **Which pen** do you want?
- **Bütün arkadaşlarımı** seviyorum. = I love **all my friends**.

### Comparison Examples

| Without Accusative (Indefinite) | With Accusative (Definite) |
|--------------------------------|---------------------------|
| Yarın araba alıyor musun? = Are you buying a car tomorrow? | Yarın **o arabayı** alıyor musun? = Are you buying **that car** tomorrow? |
| Evde maç izliyoruz. = We're watching a match at home. | Evde **maçı** izliyoruz. = We're watching **the match** at home. |
| Pınar elbise ütülüyor. = Pınar is ironing a dress. | Pınar **elbisesini** ütülüyor. = Pınar is ironing **her dress**. |
| Seda pasta yiyor. = Seda is eating cake. | Seda **pastayı** yiyor. = Seda is eating **the cake**. |
| Bir ceket almak istiyorum. = I want to buy a jacket. | **Bu ceketi** almak istiyorum. = I want to buy **this jacket**. |

## SUMMARY: KEY GRAMMAR POINTS

### 1. Possessive Suffixes (İyelik Ekleri)
- Show ownership
- Follow vowel harmony
- 1st person: -(i)m / -(i)miz
- 2nd person: -(i)n / -(i)niz
- 3rd person: -(s)i / -ları/-leri

### 2. Reflexive "Kendi" (Self)
- Used to emphasize the subject
- Takes possessive suffixes: kendim, kendin, kendisi, kendimiz, kendiniz, kendileri

### 3. "Hep" (All)
- hepimiz = all of us
- hepiniz = all of you
- hepsi = all of them

### 4. Accusative Case (Belirtme Eki)
- Used for definite/specific objects
- Answers "Kimi?" or "Neyi?"
- Suffixes: -(y)ı, -(y)i, -(y)u, -(y)ü
- Buffer 'y' between vowels

### 5. Country - Nationality - Language
- Language suffix: -cA / -çA
- Nationality: often -lı/-li or -lu/-lü
