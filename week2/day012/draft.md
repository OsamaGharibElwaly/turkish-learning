# Turkish Colors — Renkler 🎨

The Turkish word for **color** is **renk**.

## 1. Basic Colors — Temel Renkler

| Turkish          | English |
| ---------------- | ------- |
| **kırmızı**      | red     |
| **mavi**         | blue    |
| **sarı**         | yellow  |
| **yeşil**        | green   |
| **siyah / kara** | black   |
| **beyaz / ak**   | white   |

## 2. Secondary & Common Colors — Diğer Yaygın Renkler

| -------------- | --------- |
| **turuncu**    | orange    |
| **mor**        | purple    |
| **pembe**      | pink      |
| **kahverengi** | brown     |
| **gri**        | gray      |
| **lacivert**   | navy blue |

## 4. Light & Dark Colors

You can use **açık** and **koyu** to describe shades.

* **açık** = light
* **koyu** = dark

### Examples

* **açık mavi** = light blue
* **açık yeşil** = light green
* **koyu kırmızı** = dark red
* **koyu mavi** = dark blue

### Important Grammar Rule

In Turkish, the **color usually comes before the noun**, just like an adjective:

* **kırmızı araba** = red car
* **mavi gömlek** = blue shirt
* **beyaz ev** = white house
* **siyah çanta** = black bag
* **yeşil gözler** = green eyes

**Pattern:**

> **Color + Noun**
> **kırmızı + araba → kırmızı araba**
> red + car → red car
