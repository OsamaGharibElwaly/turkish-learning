## 🎯 **Bonus Tips for Using These Phrases**

### **Pronunciation Keys:**
- **c** = "j" as in *jam*
- **ç** = "ch" as in *chat*
- **ğ** = silent, lengthens the preceding vowel
- **ı** = "uh" sound (like the 'a' in *about*)
- **ş** = "sh" as in *ship*
- **ö** = like the 'eu' in *Europe*
- **ü** = like the 'u' in *flute* (rounded lips)

### **Formal vs. Informal:**
- Use **-siniz/-mısınız** endings for formal situations (strangers, elders, officials)
- Use **-sin/-mısın** endings for informal situations (friends, family, peers)
- When in doubt, **always use formal**

Learn 5 phrases per day. In 17 days, you'll master all 85! Practice them out loud every morning.
