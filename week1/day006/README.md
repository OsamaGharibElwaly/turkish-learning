This chapter is one of the **most important A1 Turkish lessons** because it teaches you how to **talk about your daily life** using the **Present Continuous Tense (Şimdiki Zaman)**. Once you master this lesson, you'll be able to describe your routine, hobbies, work, study, and ask people what they are doing.

---

# Lesson Objectives (BECERİLER)

## 1. Günlük hayatı anlatma

**Talking about daily life**

You'll learn how to describe your daily routine.

Examples:

> Ben saat yedide kalkıyorum.
>
> I wake up at 7.

> Kahvaltı ediyorum.
>
> I have breakfast.

> İşe gidiyorum.
>
> I'm going to work.

---

## 2. Boş zamanları değerlendirme

Talking about **free time**

Examples

> Kitap okuyorum.
>
> I read books.

> Film izliyorum.
>
> I'm watching movies.

> Spor yapıyorum.
>
> I do sports.

---

## 3. İstekleri ifade etme

Expressing **wants**

You'll learn

Example

>
> I want to go home.

# Grammar (Dil Bilgisi)

There are **four major grammar topics**

---

# 1. Şimdiki Zaman

## Present Continuous Tense

Equivalent to

> am
>
> is
>
> are
>
> doing

It is used for

* happening now
* near future
* routines (sometimes)

Examples

Şimdi ders çalışıyorum.

I'm studying now.

---

Yarın İstanbul'a gidiyorum.

I'm going to Istanbul tomorrow.

(planned future)

---

Her gün spor yapıyorum.

I exercise every day.

(routine)

---

# How to Form It

Formula

```
Verb Stem
+
(Iyor)
+
Personal Ending
```

Example

Gelmek

↓

gel

↓

gel + iyor

↓

geliyor

↓

geliyorum

I am coming

---

# Personal Endings

| Pronoun | Ending  | Example      |
| ------- | ------- | ------------ |
| Ben     | -um/-üm | geliyorum    |
| Sen     | -sun    | geliyorsun   |
| O       | —       | geliyor      |
| Biz     | -uz     | geliyoruz    |
| Siz     | -sunuz  | geliyorsunuz |
| Onlar   | -(lar)  | geliyorlar   |

---

# Choosing ıyor / iyor / uyor / üyor

Turkish follows **vowel harmony**.

| Last vowel | Use  |
| ---------- | ---- |
| a ı        | ıyor |
| e i        | iyor |
| o u        | uyor |
| ö ü        | üyor |

Examples

Bakmak

↓

bakıyor

---

Gitmek

↓

gidiyor

---

Koşmak

↓

koşuyor

---

Görmek

↓

görüyor

---

# Verbs ending in vowels

Some verbs end in vowels.

Example

Beklemek

↓

bekle

↓

bekliyor

---

Oynamak

↓

oyna

↓

oynuyor

---

Aramak

↓

ara

↓

arıyor

Notice

ara

NOT

arayor

Instead

arıyor

# Irregular Verbs

## Yemek

```
ye

↓

yiyor
```

yeyor ❌

↓

# Negative Form

Formula

```
Verb

+

-ma / -me

+

(Iyor)
```

Examples

Gelmiyorum.

I'm not coming.

---

Okumuyorum.

I'm not reading.

---

Dinlemiyorum.

I'm not listening.

---

# Questions

Simply add

```
mi mı mu mü
```

after the verb.

Examples

Geliyor musun?

Are you coming?

---

Çalışıyor musun?

Are you working?

---

Kitap okuyor musun?

Are you reading a book?

---

Negative Questions

Gelmiyor musun?

Aren't you coming?

---

Çalışmıyor musun?

Aren't you working?

---

| Geliyor    | Gelmiyor    | Geliyor mu?    | Gelmiyor mu?      |
| Geliyoruz  | Gelmiyoruz  | Geliyor muyuz? | Gelmiyor muyuz?   |

# 2. Yönelme Durumu (-A / -E)

This is called the **Dative Case**.

Meaning

> to
>
> toward

Examples

Okula gidiyorum.

I'm going to school.

---

Eve dönüyorum.

I'm returning home.

---

Markete gidiyorum.

I'm going to the market.

---

Arkadaşıma telefon ediyorum.

I'm calling my friend.

---

Remember

Gitmek almost always uses

```
Noun + A/E
```

---

# 3. Uzaklaşma Durumu (-Dan / -Den)

The **Ablative Case**

Means

> from

Examples

Evden çıkıyorum.

I'm leaving home.

---

Okuldan geliyorum.

I'm coming from school.

---

İşten çıkıyorum.

I'm leaving work.

---

Ankara'dan geliyorum.

I'm coming from Ankara.

---

# 4. -mak istemek

Expressing Wants

Formula

```
Verb + mak/mek

+

istemek
```

Examples

Gitmek istiyorum.

I want to go.

---

Uyumak istiyorum.

I want to sleep.

---

Kitap okumak istiyorum.

I want to read a book.

---

Türkçe öğrenmek istiyorum.

I want to learn Turkish.

---

# Rule of Thumb

Think of this lesson as five building blocks:

| Topic           | Rule                                                 |
| --------------- | ---------------------------------------------------- |
| Şimdiki Zaman   | Action happening now or planned soon → **geliyorum** |
| Negative        | Add **-ma/-me** → **gelmiyorum**                     |
| Question        | Add **mi/mı/mu/mü** → **geliyor musun?**             |
| Dative (-A/-E)  | Movement **to** somewhere → **okula gidiyorum**      |
| Ablative (-DAn) | Movement **from** somewhere → **evden çıkıyorum**    |
| istemek         | Express wants → **gitmek istiyorum**                 |
