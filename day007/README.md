### 1. Question Words for Movement
Before learning the grammar cases, you need to know how to ask about destinations and origins.
*   **Nereye?** = Where to? (Destination)
*   **Nereden?** = Where from? (Origin)
*   **Kime?** = To whom?
*   **Kimden?** = From whom?

**Examples from the text:**
*   *Nereden geliyorsun?* (Where are you coming from?) $\rightarrow$ *Ev**den** geliyorum.* (I am coming **from** home.)
*   *Nereye gidiyorlar?* (Where are they going?) $\rightarrow$ *Okul**a** gidiyorlar.* (They are going **to** school.)

### 2. Grammar Rule 1: The "To" Case (Yönelme Durumu / Dative Case)
This case shows the **destination, target, or direction** of an action. It translates to **"to"** or **"towards"** in English.

**The Suffix:** `-(y)a` or `-(y)e`
*   **Vowel Harmony:** Turkish follows 2-way vowel harmony for this suffix.
    *   If the last vowel of the word is **a, ı, o, u** $\rightarrow$ add **-a**
    *   If the last vowel of the word is **e, i, ö, ü** $\rightarrow$ add **-e**
*   **Buffer Letter "y":** If the word already ends in a vowel, you must add a "y" to separate the vowels.
    *   *Oku* (read) $\rightarrow$ *Oku**ya*** (Note: *Okul* (school) ends in a consonant, so it is *Okul**a***)
    *   *Kapı* (door) $\rightarrow$ *Kapı**ya***

**Exceptions for Pronouns:**
Personal pronouns change slightly when taking the dative suffix. Notice the buffer letter **"n"**:
*   Ben (I) + e $\rightarrow$ **Bana** (To me)
*   Sen (You) + e $\rightarrow$ **Sana** (To you)
*   O (He/She/It) + n + a $\rightarrow$ **Ona** (To him/her/it)

---

### 3. Important Rule: Consonant Softening (Ünsüz Yumuşaması)
The textbook explicitly highlights this rule in both English and Arabic boxes. 
When a word ends in the voiceless consonants **p, ç, t, k**, and you add a suffix that starts with a vowel, the consonant "softens" to protect the flow of speech:
*   **p $\rightarrow$ b** (*Kitap* $\rightarrow$ *Kitab**a*** - to the book)
*   **ç $\rightarrow$ c** (*Ağaç* $\rightarrow$ *Ağac**a*** - to the tree)
*   **t $\rightarrow$ d** (*Kanat* $\rightarrow$ *Kand**a*** - to the wing)
*   **k $\rightarrow$ g / ğ** (*Renk* $\rightarrow$ *Reng**e*** - to the color)

---

### 4. Grammar Rule 2: The "From" Case (Uzaklaşma Durumu / Ablative Case)
This case shows **origin, separation, or moving away** from something. It translates to **"from"** in English. It is also used for expressing likes, dislikes, and fears.

**The Suffix:** `-dan / -den / -tan / -ten`
This suffix follows **4-way vowel harmony** AND **consonant harmony**:
1.  **Vowels:** (a, ı, o, u) take **-a**; (e, i, ö, ü) take **-e**.
2.  **Consonants:** If the word ends in a "hard" voiceless consonant (f, s, t, k, ç, ş, h, p), use **-t**. Otherwise, use **-d**.
    *   *Ev* (house) $\rightarrow$ *Ev**den*** (From the house)
    *   *Otobüs* (bus) $\rightarrow$ *Otobüs**ten*** (From the bus - ends in 's', so we use 't')
    *   *İş* (work) $\rightarrow$ *İş**ten*** (From work)

**Special Uses of the "From" Case:**
*   **Getting off/out:** *Otobüs**ten** inmek* (To get off the bus), *Sınıf**tan** çıkmak* (To leave the classroom).
*   **Emotions:**
    *   *...den hoşlanmak* = To like (e.g., *Romantik filmler**den** hoşlanıyorum* - I like romantic films).
    *   *...den nefret etmek* = To hate (e.g., *İş**ten** nefret ediyorum* - I hate work).
    *   *...den korkmak* = To be afraid of (e.g., *Köpek**ten** korkuyorum* - I am afraid of dogs).

### 1. Grammar: Expressing Desires ("I want to...")
To say you want to do an action, you combine the **infinitive form of the verb** (`-mak` or `-mek`) with the verb **istemek** (to want).

**The Formula:** 
`Verb Root + -mak / -mek` + `iste` + `Personal Suffix`

*   **Vowel Harmony:** 
    *   If the verb root has a "back" vowel (a, ı, o, u), use **-mak** (e.g., *yap**mak*** - to do).
    *   If it has a "front" vowel (e, i, ö, ü), use **-mek** (e.g., *git**mek*** - to go).
*   **Conjugation:** The word *istemek* takes the standard Present Continuous tense suffixes (`-iyorum, -iyorsun`, etc.).

**Examples from your text:**
*   *Ben bir bilet al**mak istiyorum**.* (I **want to buy** a ticket.)
*   *Biz oraya git**mek istemiyoruz**.* (We **do not want to go** there.)
*   *Dışarı çık**mak istiyor musunuz**?* ( **Do** you **want to go** out?)
*   *Kızım öğretmen ol**mak istiyor**.* (My daughter **wants to be** a teacher.)

---

### 2. Grammar: Permission & Requests ("May I?" / "Can you?")
To express ability ("I can"), ask for permission ("May I?"), or make a polite request ("Can you?"), Turkish uses the suffix **`-(y)Abil`**.

**The Formula:**
`Verb Root + -(y)abil / -(y)ebil` + `mi` + `Personal Suffix`

*   **Vowel Harmony:** Use **-abil** for back vowels, **-ebil** for front vowels.
*   **Buffer "y":** If the verb ends in a vowel, add a "y" (e.g., *başla**y**abilirim* - I can start).

#### A. Asking for Permission (İzin)
You use this when asking if **you** are allowed to do something.
*   *İçeri gir**ebilir miyim**?* ( **May I** come in?)
*   *Bir soru sor**abilir miyim**?* ( **May I** ask a question?)
*   *Pencereyi aç**abilir miyim**?* ( **May I** open the window?)

#### B. Making a Request (Rica)
You use this when asking **someone else** to do something for you.
*   *Cevap ver**ebilir misin**?* ( **Can you** answer? - *informal/singular*)
*   *Tekrar ed**ebilir misiniz**?* ( **Can you** repeat? - *formal/plural*)
*   *Tahtaya yaz**abilir misiniz**?* ( **Can you** write on the board?)
