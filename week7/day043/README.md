## 1. Grammar: Gereklilik Kipinin Hikâyesi

-malıydım / -meliydin / -malıydı = should have / ought to have

We use this form to talk about past duties, advice, or things we regret not doing.

| Turkish                                | English                                                  |
| -------------------------------------- | -------------------------------------------------------- |
| Daha erken çıkmalıydım.                | I should have left earlier.                              |
| Bana söylemeliydin.                    | You should have told me.                                 |
| Yalan söylememeliydin.                 | You shouldn't have lied.                                 |
| İşlerini son dakikaya bırakmamalıydın. | You shouldn't have left your work until the last minute. |
| Mavi gömleği almalıydım.               | I should have bought the blue shirt.                     |
| Onlar bunu anlatmamalılardı.           | They shouldn't have told this.                           |

### Grammar pattern

- Positive: verb stem + `-malı/-meli` + personal ending + `-ydı`
- Negative: verb stem + `-mamalı/-memeli` + personal ending + `-ydı`

Examples:

- Gitmeliydim. — I should have gone.
- Gitmemeliydim. — I shouldn't have gone.
- Yapmalıydın. — You should have done it.
- Yapmamalıydın. — You shouldn't have done it.

# İstanbul Türkçe Öğretim Seti B1 — Zorunluluk (Necessity)

## 1. Grammar: Zorunda olmak / Mecburiyetinde olmak / Mecbur olmak

These structures express necessity or obligation — something you have to do.

| Turkish                           | English                                |
| --------------------------------- | -------------------------------------- |
| Sınava girmek zorundayım.         | I have to take the exam.               |
| Ödevi bitirmek mecburiyetindeyiz. | We are obliged to finish the homework. |
| Ona gerçeği anlatmaya mecburum.   | I have to tell him/her the truth.      |
| Daha çok çalışmak zorunda kaldık. | We had to work more.                   |
| Evde kalmak zorunda kaldım.       | I had to stay at home.                 |

Important difference:

- Zorunda olmak — to have to / must
- Mecbur olmak — to be obliged to
- Zorunda kalmak — to have to because circumstances force you to
- -malı/-meli — should / ought to; often advice or necessity
