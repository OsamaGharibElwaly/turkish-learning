## 2. Grammar: -sA bile / -sA da

This structure means even if / even though.

It expresses that the main action will happen regardless of whether the condition in the subordinate clause happens.

| Structure         | Meaning               |
| ----------------- | --------------------- |
| Fiil + -sA + bile | Even if               |
| Fiil + -sA + da   | Even if / Even though |

Examples:

- Sen gelmesen bile biz gideceğiz.
  - Even if you don't come, we will go.
- Siz kabul etmeseniz de bu ayran bozuk.
  - Even if you don't accept it, this ayran is spoiled.
- Hemen hazırlanıp çıksak bile filme yetişemeyiz.
  - Even if we get ready and leave immediately, we won't make it to the movie.
- Artık istesem de geri dönemem.
  - Even if I want to, I can't go back anymore.

Important conjugation pattern:

| Person | Gelmek → -sA bile |
| ------ | ----------------- |
| Ben    | gelsem bile       |
| Sen    | gelsen bile       |
| O      | gelse bile        |
| Biz    | gelsek bile       |
| Siz    | gelseniz bile     |
| Onlar  | gelseler bile     |

Notice that the personal suffix comes after `-sA`.

# İstanbul Kitabı B1 – İsim + (y)A rağmen

## 1. Grammar: Noun + (y)A rağmen

Meaning: Despite / In spite of

This structure expresses contrast: something happens even though there is an opposing condition or circumstance.

The structure is:

\\[ \text{Noun} + \text{Dative suffix} + rağmen \\]

The dative suffix follows the vowel harmony rules:

| Noun ending | Suffix | Example               |
| ----------- | ------ | --------------------- |
| Consonant   | -a     | zorluk + a = zorluğa  |
| Consonant   | -e     | rağmen? No: hata + ya |
| Vowel       | -ya    | hava + ya = havaya    |
| Vowel       | -ye    | aile + ye = aileye    |

Remember: `rağmen` always takes the dative case.

### Examples from your book

1\. Fırtınaya rağmen gemi yola çıktı.

Despite the storm, the ship set sail.

- fırtına = storm
- fırtınaya = to the storm
- rağmen = despite

2\. Bütün hatalarına rağmen onu affedeceğim.

Despite all his/her mistakes, I will forgive him/her.

3\. Güneşli havaya rağmen piknik planlarımızı iptal ettik.

Despite the sunny weather, we cancelled our picnic plans.

4\. Kalabalığına rağmen İstanbul'u seviyorum.

Despite its crowdedness, I love Istanbul.

### Important distinction: -masına rağmen vs. -masına rağmen

You will also encounter:

`Fiil + -masına/-mesine rağmen`

This means despite doing something / despite the fact that something happens.

Examples:

- Çok çalışmasına rağmen sınavı geçemedi.
  - Despite studying hard, he couldn't pass the exam.
- Yağmur yağmasına rağmen dışarı çıktık.
  - Despite it raining, we went outside.

Compare:

- Yağmura rağmen dışarı çıktık. (Despite the rain.)
- Yağmur yağmasına rağmen dışarı çıktık. (Despite it raining.)

Both are correct, but their grammatical constructions differ.

# A. İNSAN HAYALLERİ İLE YAŞAR

This lesson introduces a very useful Turkish structure for expressing wishes, dreams, suggestions, and imagined situations.

The main structure is:

Verb stem + -sA / -sE + personal ending

Examples:

| Turkish                   | English                              |
| ------------------------- | ------------------------------------ |
| Keşke tatile gitsem.      | I wish I could go on vacation.       |
| Keşke hiç yağmur yağmasa. | I wish it would never rain.          |
| Bugün Ali'yi aramasam mı? | Should I perhaps not call Ali today? |
| Bugün piknik yapsak mı?   | Shall we have a picnic today?        |

## 1. Grammar: -sA / -sE (Dilek-Şart Kipi)

This structure is called Dilek-Şart Kipi (wish/conditional mood).

It has two important uses:

A. Expressing wishes and dreams

Usually with `keşke`:

- Keşke Türkiye'de yaşasam. — I wish I lived in Türkiye.
- Keşke daha fazla zamanım olsa. — I wish I had more time.
- Keşke İngilizceyi ana dilim gibi konuşsam. — I wish I spoke English like a native.

B. Making suggestions or asking yourself what to do

- Biraz dinlensem mi? — Should I get some rest?
- Dışarı çıksak mı? — Shall we go out?
- Onu arasam mı? — Should I call him?

### How to conjugate it

Let's use `gitmek` (to go), `yapmak` (to do), and `gelmek` (to come).

| Person | Gitmek    | Yapmak   | Gelmek   |
| ------ | --------- | -------- | -------- |
| Ben    | gitsem    | yapsam   | gelsem   |
| Sen    | gitsen    | yapsan   | gelsen   |
| O      | gitse     | yapsa    | gelse    |
| Biz    | gitsek    | yapsak   | gelsek   |
| Siz    | gitseniz  | yapsanız | gelseniz |
| Onlar  | git seler | yapsalar | gelseler |

Note: The correct form in the last row for `gitmek` is gitseler.

Negative forms:

- gitmesem = if I didn't go / I wish I didn't go
- yapmasak = if we didn't do it
- gelmese = if he/she didn't come
- aramasam = if I didn't call

### A useful distinction: `Keşke` vs. `Mesela`

Both can introduce imaginary situations, but they have slightly different feelings.

- `Keşke genç olsam.` = I wish I were young. (A wish, perhaps with regret.)
- `Mesela genç olsam...` = What if I were young... (An imaginative scenario.)
- `Keşke tatile gitsem.` = I wish I could go on vacation.
- `Mesela şimdi tatile gitsem...` = Imagine if I went on vacation right now\...

Here is the summary of how keşke works:
• Core Meaning: It strictly means "I wish" or "if only".
• Speaker's Perspective: The person making the wish is always "I" (the speaker), even if the sentence describes someone else's action (e.g., Keşke gitsen = I wish you would go).
• Grammar Rule: It always pairs with the conditional verb suffix (-se / -sa) plus a personal ending to show who the action belongs to.
• Other People's Wishes: To say "you wish" or "he wishes" literally, you must drop keşke and use the verb istemek (to want).
• Sarcastic "You wish!": For the English idiom "In your dreams!", Turkish uses phrases like "Rüyanda görürsün!" instead.

# DİLEK-ŞART KİPİ

This grammar point is very important.

## 1. What does **-sa / -se** do?

It can express:

### A. A wish — **Dilek**

Usually with **keşke**.

> **Keşke şimdi evde yatıp dinlensem.**  
> I wish I could lie down and rest at home now.

> **Keşke daha fazla param olsa.**  
> I wish I had more money.

> **Keşke Türkiye'de yaşasam.**  
> I wish I lived in Turkey.

---

## 2. Conditional meaning — **Şart**

The action depends on another situation.

> **Yarın hava güzel olsa da pikniğe gitsek.**

If the weather is nice tomorrow, let's have a picnic.

> **Piyangodan para kazansam hemen kendime yeni bir araba alırım.**

If I won money from the lottery, I would immediately buy myself a new car.

---

# Conjugation: Gitmek

## Positive — Olumlu

| Person | Turkish | English |
|---|---|---|
| Ben | **gitsem** | if I went / I wish I went |
| Sen | **gitsen** | if you went |
| O | **gitse** | if he/she went |
| Biz | **gitsek** | if we went |
| Siz | **gitseniz** | if you went |
| Onlar | **gitseler** | if they went |

## Negative — Olumsuz

| Person | Turkish |
|---|---|
| Ben | **gitmesem** |
| Sen | **gitmesen** |
| O | **gitmese** |
| Biz | **gitmesek** |
| Siz | **gitmeseniz** |
| Onlar | **gitmeseler** |

---

# The Question Form: `-sa / -se + mı?`

This is especially useful for **suggestions** and asking someone's opinion.

### `Gitsem mi?`

**Should I go?**

### `Gitmesem mi?`

**Should I not go? / Maybe I shouldn't go?**

Examples:

> **Kendimi çok halsiz hissediyorum. Yarın işe gitmesem mi?**  
> I feel very weak. Shouldn't I go to work tomorrow?

> **Bu yaz tatilde nereye gitsek?**  
> Where should we go on vacation this summer?

> **Bu akşam sinemaya gitsek mi?**  
> Shall we go to the cinema tonight?

> **Biraz dinlensem mi?**  
> Should I rest a little?

---

# Quick distinction: four important patterns

| Turkish | Meaning |
|---|---|
| **Keşke gitsem.** | I wish I could go. |
| **Gitsem mi?** | Should I go? |
| **Gitsek mi?** | Shall we go? |
| **Gitsem...** | If I went... / What if I went... |

### Compare:

**Keşke Türkiye'ye gitsem.**  
→ A wish.

**Türkiye'ye gitsem mi?**  
→ Asking: Should I go?

**Türkiye'ye gitsem, İstanbul'u da gezerdim.**  
→ A hypothetical condition.

**Mesela Türkiye'ye gitsem...**  
→ An imagined scenario.

---

## The key idea for this lesson 🔥

The same form **`-sa / -se`** changes meaning depending on context:

**Keşke daha genç olsam.** → *I wish I were younger.*

**Daha genç olsam daha çok seyahat ederdim.** → *If I were younger, I would travel more.*

**Daha genç olsam mı?** → *Should I become younger?* ❌ Usually unnatural because age cannot simply be changed.

**Mesela daha genç olsam...** → *What if I were younger...* ✨ An imagination.

For this lesson, your strongest pattern to memorize is:

> **Mesela + verb (-sa/-se)...**

For example:

**Mesela şimdi İstanbul'da olsam...**  
**Mesela yarın hiç çalışmasam...**  
**Mesela bütün dünyayı gezsem...**  
**Mesela hayallerimi gerçekleştirebilsem...**

These are exactly the kinds of structures you can reuse in your **B1 writing and speaking**.

# 9. Aşağıdaki durumlar olsa hayatımız nasıl değişir?

The instruction means: If the following situations happened, how would our lives change? What would we do?

The example uses the conditional structure:

`On kardeşiniz olsa, arkadaşa ihtiyacınız kalmaz.`

Here are possible speaking answers.

### 1. On kardeşiniz olsa — If you had ten siblings

On kardeşim olsa hiç yalnız kalmazdım. Birlikte gezerdik, oyun oynardık ve birbirimize yardım ederdik. Arkadaşa ihtiyacım kalmazdı.

### 2. Geleceği görseniz — If you could see the future

Geleceği görebilsem önemli kararlarımı daha dikkatli verirdim. Gelecekte karşılaşacağım zorluklara hazırlanırdım.

### 3. Beş yabancı dil bilseniz — If you knew five foreign languages

Beş yabancı dil bilsem dünyanın birçok ülkesinde insanlarla iletişim kurabilirdim. Farklı ülkelerde çalışabilir ve seyahat edebilirdim.

### 4. Görünmez olsanız — If you were invisible

Görünmez olsam dünyayı farklı bir açıdan keşfederdim. Ancak insanların özel hayatına saygı gösterirdim.

### 5. Hayvanlarla konuşabilseniz — If you could talk to animals

Hayvanlarla konuşabilsem onların ihtiyaçlarını ve duygularını anlamaya çalışırdım. Onlara yardım eder ve doğayı daha iyi korurdum.

### 6. On çocuğunuz olsa — If you had ten children

On çocuğum olsa çok büyük bir ailem olurdu. Onlarla daha fazla zaman geçirmek için hayatımı iyi planlamam gerekirdi.

### 7. Dört kollu olsanız — If you had four arms

Dört kolum olsa aynı anda daha fazla iş yapabilirdim. Ev işlerini daha hızlı bitirir ve farklı şeylerle aynı anda ilgilenirdim.

### 8. Sadece bir yıl ömrünüz kalsa — If you had only one year left to live

Sadece bir yıl ömrüm kalsa ailemle ve sevdiklerimle daha fazla zaman geçirirdim. Hayallerimi gerçekleştirmeye çalışır ve dünyayı gezmek isterdim.

### 9. Ünlü bir aktör/aktris olsanız — If you were a famous actor/actress

Ünlü bir aktör olsam filmlerde farklı karakterleri canlandırırdım. Kazandığım paranın bir kısmını ihtiyaç sahibi insanlara yardım etmek için kullanırdım.

### 10. Ülkenin başkanı olsanız — If you were the president of the country

Ülkenin başkanı olsam eğitim ve sağlık sistemlerini geliştirmeye çalışırdım. Gençlere daha fazla iş fırsatı sunar ve adalete önem verirdim.

### 11. Hafızanızı tamamen kaybetseniz — If you completely lost your memory

Hafızamı tamamen kaybetsem ailemi ve geçmişimi yeniden tanımaya çalışırdım. Yeni şeyler öğrenmeye başlar ve hayatımı yeniden kurardım.

## Grammar focus: `-sA` + `-Ar/-Ir` or `-rdI`

Notice this important pattern in the answers:

Condition + imagined result

| Condition       | Result                           |
| --------------- | -------------------------------- |
| Beş dil bilsem  | farklı ülkelerde çalışabilirdim. |
| Geleceği görsem | daha dikkatli karar verirdim.    |
| Görünmez olsam  | dünyayı keşfederdim.             |
| Başkan olsam    | eğitim sistemini geliştirirdim.  |

Two common result patterns:

- `-Ar / -Ir`: a possible or general result.
- `-ArdI / -IrdI`: an imagined or hypothetical result.

Examples:

- `Çok param olsa dünyayı gezerim.` — If I have a lot of money, I'll travel the world.
- `Çok param olsa dünyayı gezerdim.` — If I had a lot of money, I would travel the world.

Your most important takeaway: In this lesson, practise using `-sA/-sE` not only with `keşke`, but also to imagine different lives, express wishes, make suggestions, and discuss hypothetical situations.

## 3 قواعد مهمة جدًا تحفظها مع التركيبات

1\. الفعل + اللاحقة المناسبة

- `karar vermek` → `Yapmaya karar verdim.`\
  I decided to do it.
- `alışmak` → `Yeni hayatıma alıştım.`\
  I got used to my new life.

2\. الصفات غالبًا تحتاج فعلًا مساعدًا

- `mutlu olmak` → to be happy
- `emin olmak` → to be sure
- `sabırlı olmak` → to be patient

3\. لا تحفظ التركيبة بدون مثال شخصي

مثلًا بدل حفظ:

`Kendini geliştirmek = To improve oneself`

اكتب:

`Türkçe öğrenerek kendimi geliştirmek istiyorum.`

I want to improve myself by learning Turkish.
